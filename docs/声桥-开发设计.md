# 声桥开发说明

声桥以 Windows 自带的 A2DP Sink 接收手机和平板的蓝牙媒体音频。Windows 负责传输、解码和播放，声桥管理每台设备的连接和录制端点。

- `SoundBridge.App` 提供 WPF 设备列表、托盘、单实例和当前用户自启动。退出时先取消后台操作并关闭连接。
- `SoundBridge.Core` 按设备 ID 跟踪 WinRT 会话。连接关闭后才能释放该设备的占用，旧会话的事件不能更新后来建立的连接。
- 新连接的活动 A2DP 录制端点会设为 50%。Windows 重新配对后可能留有旧端点，程序只处理唯一匹配的活动端点。
- 自动恢复声音默认关闭。启用后，程序等待对应的活动播放会话，短暂静音后恢复。匹配依赖当前 Windows A2DP 播放会话标识中的录制端点 GUID。保留用户已有的静音状态。

## 已知限制

双设备可以同时连接。测试中，小米平板单播时 12 秒收到约 12 秒 PCM；同一蓝牙适配器同时接收另一台设备时，小米的输入供帧不足。切换 Windows 输出设备和两台音源的 Wi‑Fi 频段都未消除这一现象。具体原因可能涉及 Windows A2DP、驱动、共享适配器调度或射频干扰。当前版本以单路稳定播放为目标。

.NET 11 WPF 在自包含捆绑发布时需要将 `DirectWriteForwarder.dll`、`System.Printing.dll` 和 `ijwhost.dll` 与 exe 一起分发。项目文件和打包脚本都保留它们。[上游问题](https://github.com/dotnet/wpf/issues/11842)
